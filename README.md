# Genus 🐰

> Master German grammatical gender — **der**, **die**, **das** — one word at a time.

**Live app → [de-practice.vercel.app](https://de-practice.vercel.app)**

---

## What is it?

Genus is a flashcard-style PWA that drills you on German noun genders. A word appears on screen, you tap the correct article, and the app gives you immediate feedback along with the grammar rule that explains *why*. Words never repeat in a session, difficulty scales with your CEFR level, and a bunny keeps you company while it fetches the next batch.

---

## Features

- **Unlimited words** — powered by Gemini, so the word pool never runs dry
- **5 CEFR levels** — A1 through C1, affecting both vocabulary and definition complexity
- **Instant feedback** — correct → green, wrong → red, always shows the right answer
- **Grammar rules** — every word comes with a concise gender rule in German (e.g. *Nomen auf -ung sind meistens feminin*)
- **Definitions on demand** — tap "Definition anzeigen" to see a DE + EN explanation tuned to your level
- **Session accuracy** — live % counter in the header
- **Streak tracking** — consecutive correct answers, resets each session
- **All-time best** — 🏆 persisted in localStorage across sessions
- **End session summary** — accuracy %, correct/wrong/total, best streak, motivational message
- **No repeated words** — seen words stored in localStorage, sent to Gemini so it avoids them
- **Keyboard shortcuts** — `1` die · `2` der · `3` das · `Enter/Space` next word
- **PWA** — installable on Android & iOS home screen, no app store needed

## Running locally

```bash
# 1. Clone
git clone git@github.com:achreftrablesi/de-practice.git
cd de-practice

# 2. Install
npm install

# 3. Add your Gemini API key (get one free at aistudio.google.com)
echo "GEMINI_API_KEY=your_key_here" > .env.local

# 4. Run
npm run dev
# → http://localhost:3000
```

## How the LLM integration works

Each request asks Gemini for a **batch of words** (5 on first load for speed, 10 thereafter). The response is constrained via a **JSON schema** (`responseSchema`) so the model can't return malformed output — no markdown fences, no trailing text, article is enforced as an enum of `"der" | "die" | "das"`.

A new batch is pre-fetched silently when 3 words remain in the queue, so there's no loading gap mid-session.

## Shortcuts taken (known limitations)

These are intentional v1 trade-offs, not oversights:

### No user accounts
Streak, seen words, and level are stored in `localStorage` — per device, per browser. If a friend clears their browser or switches devices, progress is lost. A proper backend (e.g. Firebase Auth + Firestore) would fix this but adds significant setup and cost.

### No offline support
The app is a PWA but doesn't cache API responses. If you're offline, word fetching fails. A service worker with a local word cache would be needed for true offline play.

### No curated word list
Words are generated by Gemini on the fly. Occasionally a word may be obscure, repeated across level boundaries, or (rarely) have an incorrect article. A human-reviewed seed list per level would be more reliable.

### Seen words are capped at 150
To keep the Gemini prompt short, only the last 150 seen words are sent as the exclusion list. In long sessions a word could theoretically reappear after the cap.

### No spaced repetition
Words you get wrong are not scheduled to reappear. A proper SRS (like Anki's algorithm) would significantly improve retention but requires a backend to store per-word history.

### Single-device streak
The all-time best streak is per-device localStorage. There's no global leaderboard or cross-device sync.

### Icons are placeholders
The PWA icons (192×192 and 512×512) are minimal grey squares. Proper branded icons would improve the home screen experience.
